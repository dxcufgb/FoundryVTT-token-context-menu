# Changelog

## 1.2.3

- Optional integration with Dxcufgb's Debug Recorder: while the GM records, the menu adds a snapshot of its state (whether the menu is active, which optional modules were detected, entry counts, error counters) and breadcrumbs of what it did (menu built, entry clicked, sub-menu opened, players' menu opened or closed) to the bug report. Never token, actor or user names. Nothing changes when the recorder is not installed.
